Warden — Feature List
PROJECT NAME: Warden (Security & Vulnerability Testing Suite)
Stack: OWASP ZAP + Python + Docker
Target: Trajectory / Phoenix endpoints
Core Differentiator: Security Testing

Automated vulnerability scans (SQL injection attempts, XSS, common auth bypass patterns)
Broken access control checks — explicitly verifies User A cannot read/modify User B's applications or documents
Input fuzzing on key endpoints — malformed payloads, oversized inputs, unexpected types
Structured vulnerability report with severity ratings (mirrors Aegis's reporting approach, but for security findings)
Fills a QA specialization almost no self-taught portfolio touches — standout rather than a third variation of functional testing
